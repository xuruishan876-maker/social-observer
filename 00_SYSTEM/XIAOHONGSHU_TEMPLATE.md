# ✨ 小红书文案模板 + AI 指令

**专为小红书平台优化的文案生成指南**

---

## 小红书内容特征（必读）

### 平台要求
- 原创率 ≥ 80%（小红书对原创要求更严）
- 避免违规词汇："保证""只要""必定"等承诺词
- 避免引流到外部（微信、企业微信等）
- 商业合作必须标注"#商业合作"

### 用户期待
- 50% 深度洞察 / 人性观察
- 30% 具体案例 / 故事讲述
- 20% 实践启发 / 思维模型

---

## 标题公式（最重要）

### ✅ 推荐标题类型

**反常识 + 共鸣**
- "为什么聪明的创业者反而容易失败？"
- "你消费的钱，99% 流向了这个地方"
- "小镇青年的消费观，说明了什么"

**现象 + 疑问 + 思考**
- "你以为的优势，其实是最大的劣势"
- "有很多资源，但一单钱都赚不到，为什么？"

**数据 + 洞察**
- "这个数据，改变了我对消费的认知"
- "深圳创业者的真实困境"

### ❌ 避免的标题

- "震惊""万万没想到"（小红书严打）
- 过度承诺（"必定成功""一定赚钱"）
- 纯引流标题

## 文案结构（1500-2000 字）

### 第一部分：开头（200-250 字）

**目的**：引起共鸣 + 制造思考

**写法**：
1. 一个普遍现象或困境
2. 大多数人的误解
3. 真实情况是什么（制造反差）

**例子**：
```
我最近跟很多创业者聊天，他们都在说：
"我有供应商、有客户、有信息、有关系，
但就是不成交，钱根本赚不到。"

大家都认为问题是"资源不够"。

但我观察发现，问题根本不是资源。
是这些资源之间，没有成交路径。
```

---

### 第二部分：现象分析（300-400 字）

**目的**：用故事和数据支撑观点

**写法**：
- 具体人物故事
- 具体事例或数据
- 普遍性规律

**例子**：
```
我见过一个淘宝卖家，有 5 个供应商、1000+ 忠实客户、
行业内的热点信息，还有专业的采购渠道。

KPI 都很漂亮。

但就是生意不好，每个月入不敷出。

后来我问他："你怎么从获取客户，到他最后下单的？"

他说不出来。

他有客户群，但从群里获得线索，到最后成交，
中间的步骤完全混乱。没有标准化的跟进流程。
没有时间点提醒。没有关键转化点的把控。

就这一点，就把 90% 的潜在订单浪费了。
```

---

### 第三部分：深层洞察（400-500 字）

**目的**：从现象升级到人性和商业规律

**写法**：
- 为什么会这样（人性）
- 隐藏的商业逻辑
- 可复用的规律

**例子**：
```
【为什么会这样？】

因为大多数人觉得"有资源"就等于"有机会"。

但资源只是原料，成交是产品。

原料和产品之间，需要一条完整的生产线。

【这条生产线是什么？】

1. 识别：从海量信息里，找出真正的机会
2. 吸引：怎么让对方注意到你
3. 沟通：建立信任的过程
4. 转化：触发购买决策的那一刻
5. 交付：完成承诺
6. 复购：长期关系

【真相是什么？】

大多数创业者有资源，但没有系统。

他们用"碎片化"的方式做生意：
- 有渠道但没有标准
- 有客户但没有流程
- 有信息但没有判断标准

所以再多资源都在浪费。
```

---

### 第四部分：实践启发（300-350 字）

**目的**：给读者可以落地的思考

**写法**：
- 反转思维方式
- 可以怎么做
- 问自己的问题

**例子**：
```
【思维反转】

不是"资源多就赚钱"。
而是"系统清晰就赚钱"。

【你可以思考的几个问题】

1. 我从客户获取线索，到他最后下单，中间有几步？
   每一步的成功率是多少？

2. 我的成交流程，能被别人复制吗？
   如果不能，说明我没有系统。

3. 我有多少潜在订单，卡在了某一环节？
   （大多数人会惊讶地发现：90%）

【一个建议】

不要急着找更多资源。
先把现有的资源，用一个清晰的系统连接起来。

这比找新资源，效果快 100 倍。
```

---

### 第五部分：结尾（150-200 字）

**目的**：价值观输出 + 思考空间

**写法**：
- 更大的思考维度
- 鼓励反思
- 开放式结尾

**例子**：
```
【最后的思考】

在商业里，限制你的，往往不是资源的绝对数量，
而是你怎么组织这些资源。

同样的资源，在有系统的人手里，能产生 100 倍的效果。
在没有系统的人手里，就是浪费。

所以��真正稀缺的，不是资源。
而是"把资源连接起来的能力"。

你有多少资源，但却因为没有系统而浪费的？
欢迎评论区分享。
```

## AI 指令（复制给 AI 用）

### 快速版

```
我有一个商业观察想让你写成小红书文案。

首先，理解我的风格：
- 精致洞察 + 人性共鸣
- 50% 洞察 30% 案例 20% 启发
- 温暖、有品味、有启发力

现在，请为我的观察写一篇 1500-2000 字的小红书文案：

【观察标题】
[标题]

【核心现象】
[现象描述]

【我的思考】
[你的分析]

请按照以下结构生成：
1. 标题（反常识 + 共鸣）
2. 开头（引起共鸣 + 制造反差）
3. 现象分析（故事 + 数据）
4. 深层洞察（人性 + 规律）
5. 实践启发（反转思维 + 可落地建议）
6. 结尾（价值观 + 思考空间）

要求：
- 补充具体故事和例子
- 找到深层的人性或心理原因
- 保持温暖、精致的语风
- 给出可思考的问题
- 鼓励评论和讨论
```
