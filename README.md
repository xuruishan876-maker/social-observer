# 🔥 Social Observer - 内容生产系统

**从现实观察到爆款内容的完整流水线**

---

## 📊 项目定位

这是一套**内容生产系统**，专为抖音 + 小红书设计。

### 核心目标
- 每天记录有价值的商业观察（5分钟）
- 用 AI 转化成完整高质量文案（30分钟）
- 建立可复用的商业真相库（持续积累）
- 源源不断产出账号爆款内容（每周 3-5 条）

---

## 🚀 核心工作流

```
现实观察 
    ↓
快速记录（5分钟，用模板）
    ↓
AI 深度分析 + 补充信息
    ↓
生成两个平台版本文案
    ↓
标题多版本测试
    ↓
发布 + 数据反馈
    ↓
迭代优化
```

## 🎬 日常流程

### 每天（5分钟）
- 看到有趣现象 → 用模板快速记录

### 每周（30分钟）
- 打开 Claude/ChatGPT
- 粘贴 AI 系统提示词
- 粘贴这周的 2-3 个观察
- AI 生成抖音版 + 小红书版

### 每篇（10分钟）
- 检查事实、逻辑、风格
- 小改 1-2 处
- 发布
